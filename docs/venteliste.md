# Venteliste

Ting vi har bestemt å vente med. Ta dem opp igjen før lansering eller når det passer.

- **Eget domene:** koble på for eksempel mekkoo.no i stedet for `amazing-shortbread-…netlify.app`.
- **Deling og Google:** tittel, beskrivelse og forhåndsbilde (Open Graph), så siden ser pen ut når den
  deles på SMS og Facebook og finnes på Google.
- **Statistikk:** enkel, personvernvennlig telling av besøk og hvor folk faller av (for eksempel Plausible).
  Personvernsiden må oppdateres samtidig.
- **Feilvarsling:** få beskjed når noe krasjer hos brukerne.
- **Påminnelser:** e-post eller varsel før service og EU-kontroll.
- **Innhold i dashbordet:** bestemme hvilke data brukerne selv skal kunne legge inn (kilometerstand,
  kvitteringer, bilder …).
- **Kontakt på personvernsiden:** legge inn e-postadressen brukere kan skrive til (står nå bare «kontakt oss»).
